# npm packages whose install scripts are accepted, wpantry's default (replace
# it with --install-scripts FILE). wpantry warns on any other dependency that
# runs code at install time (npm's hasInstallScript, or a build a pnpm
# workspace allows). Install scripts are how most npm supply-chain attacks run.
#
# This file is the only control. OSV and the malicious-package index still
# check every locked package, but nothing else reads what an allowed script
# does: a package here runs its script unremarked, so each entry names the
# versions someone has looked at. Forms, one per line:
#   name@1.2.3   that version
#   name@^0.28   npm's caret: >=0.28.0 <0.29.0 (^1.2 is >=1.2.0 <2.0.0)
#   name@~1.2    npm's tilde: >=1.2.0 <1.3.0
#   name         every version; allowed, and discouraged
# A locked version outside its entry warns (INSTALL-SCRIPT) until someone
# reads the new script and widens the entry; a prerelease is never inside.
#
# The ranges below are the versions in use across Waffuru's repos and current
# on npm when they were set, 2026-10-31. sharp and @tailwindcss/oxide declare
# no install script at their current versions (they ship prebuilt binaries as
# optional dependencies) and stay listed for the older lockfiles that still
# run one.
esbuild@^0.28
fsevents@^2.3
sharp@^0.35
@swc/core@^1
@parcel/watcher@^2
@tailwindcss/oxide@^4

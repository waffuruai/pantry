# Notices that aren't a crate's

Licence texts `mise run notices` appends to `crates/wpantry-cli/THIRD-PARTY-NOTICES.txt`, kept here so every machine renders the same file:

| File | Source |
|---|---|
| `rust-LICENSE-MIT` | rust-lang/rust `LICENSE-MIT` at the pinned toolchain (`rust-toolchain.toml`) |
| `musl-COPYRIGHT` | musl `COPYRIGHT` at v1.2.5, the musl Rust's `*-linux-musl` targets link |
| `npm-high-impact-license` | wooorm/npm-high-impact `license` at 1.13.0, the version `scripts/popular.py` reads |

Refresh one when its source's version changes.

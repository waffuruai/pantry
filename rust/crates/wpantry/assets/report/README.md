# Standalone report viewer

`report.html` is compiled into the library. `src/reporters/html.rs` replaces its `{{PANTRY_BUNDLE}}` token with script-safe JSON (the scan, its scope, the update plan and the cache's history) and the four `{{FONT_*}}` tokens with the brand faces from `fonts/` as `data:` URLs. Keep CSS, JavaScript, fonts and images embedded so a generated report opens offline and makes no request.

The page follows `.agents/DESIGN.md` in the org workspace: the Waffuru palette (dark by default, the brand's light set on request, light in print), Instrument Serif for titles with one gold italic word, Geist for text, Geist Mono for the numbered caps labels and commands. Fail red is the one colour outside the palette; warnings are gold, verified fixes the diagram green. The PNG is the unmodified official Waffuru mark from `waffuruai/website`, `public/brand/waffuru-waffle.png` (retrieved 2026-10-29).

The page answers four questions in order, numbered as a run reads: **1 Scanned** (the inventory counts by area, every `unchecked` source as a gap, the scope and policy), **2 At risk** (one row per component, grouped by area, areas and rows in the order `SKILL.md` says to fix things), **3 Patching** (what `wpantry fix` runs unattended, what the history says was patched, what has no released fix) and **4 By hand** (numbered steps with the exact command or setting), then **5 History** (the exposure and remediation logs of `wpantry report`) when the cache has any.

Run `mise run test html` (or `node tests/html/test-viewer.cjs`) from the repository root: it renders the viewer in a fake DOM and checks that every finding kind of a fixture scan lands under its area in fix order, that gaps render as gaps, that the manual steps list every non-unattended `fix_cmd`, that the screen and print documents are well formed, plus escaping, imports and the all-clear state. `src/reporters/html.rs` checks the template itself the same way. Neither replaces opening a generated report in a browser.

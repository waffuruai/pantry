# Fonts

Instrument Serif (display) and Geist and Geist Mono (text and labels), the Waffuru brand faces, as the Latin WOFF2 subsets `ops/docs/fonts/` keeps. `src/html.rs` embeds them in every HTML report as `data:` URLs, so a report opens offline without fetching a font.

All three are licensed under the SIL Open Font License 1.1: [Instrument Serif](LICENSE-InstrumentSerif-OFL.txt), [Geist and Geist Mono](LICENSE-Geist-OFL.txt).

# wpantry-yara

The YARA engine [Pantry](https://github.com/waffuruai/pantry)'s malware scan runs on: a reader for YARA rules and a matcher for them, in safe Rust with no dependencies. The [`wpantry`](https://crates.io/crates/wpantry) library is its user; its API is `0.x` and pinned exactly by that crate.
